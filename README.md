# Verificaê

Site com registros sobre Flávio Bolsonaro (cada item com fonte, data, situação e resposta da defesa) e uma busca de checagens de boatos ("Recebeu algo no zap?").

## Rodar

Abra `site/index.html` no navegador. É um arquivo só, sem dependências.

## Atualizar as checagens

```bash
python3 scripts/fetch_checagens.py
```

No GitHub isso roda sozinho duas vezes por dia e publica o site.
